# Contributing

Thank you for helping make QR Code Toolkit better.

## Workflow

1. Search existing issues before opening a new one.
2. Fork the project and create a focused branch from `main`.
3. Install dependencies with `npm install`.
4. Make your change, keeping all processing browser-only and accessible.
5. Run `npm run lint` and `npm run build`.
6. Open a pull request describing the problem, solution, and visual changes. Include screenshots for UI work.

Please keep pull requests small, avoid paid services or tracking, and never commit secrets. By participating, you agree to the Code of Conduct.
